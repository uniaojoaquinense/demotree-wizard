DemotreeWizard - AutoSetup

Configure seu site de links em 3 passos

Sobre este aplicativo

O DemotreeWizard - AutoSetup é uma ferramenta para capítulos da Ordem DeMolay criarem, de forma rápida e segura, um site de links próprio. Em três passos ele gera: uma planilha no Google Sheets, um proxy no Cloudflare e um repositório no GitHub Pages — pronto para publicar os links e materiais do capítulo sem precisar de programação.

1 Google Sheets
2 Cloudflare
3 GitHub

Criar Planilha

Vamos criar uma planilha do Google Sheets com a estrutura pronta para seus links e configurações.

Criar Proxy

Crie um token no Cloudflare com permissão de editar Workers e cole abaixo. O worker será criado automaticamente na sua conta.

Como criar o token:

  1. Acesse dash.cloudflare.com/profile/api-tokens
  2. Clique em "Create Token"
  3. Selecione o template "Edit Cloudflare Workers"
  4. Em Account Resources, selecione sua conta (seu email)
  5. Em Zone Resources, selecione "All zones"
  6. Clique em "Continue to summary" e depois "Create Token"
  7. Copie o token (começa com xxxx) e cole abaixo

Criar Repositório

Vamos criar um repositório no GitHub com o site configurado e ativar o GitHub Pages.

Seu site foi criado com sucesso.
